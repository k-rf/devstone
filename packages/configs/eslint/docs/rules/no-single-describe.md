# no-single-describe

テストファイル内に単一の describe しか存在しない場合、冗長な describe グループ化を省略し、直接 it / test を平坦（フラット）に記述することを強制します。

## Rule Details

テスト対象に単一のコンテキスト（状況や条件による論理的な分類）しか存在しない場合、ファイル全体を単一の `describe` で囲むのは不要なインデントと階層を生み出します。
そのため、テストケース群が単一のコンテキストのみである場合は、`describe` によるグループ化を省略し、テストケース（`it` / `test`）を直接記述します。

ただし、以下の場合は本ルールの対象外（許可）となります：

- `describe` が複数存在する場合（例: `正常系` と `異常系` でコンテキストが分かれている）
- `describe` がネストしている場合
- 単一の `describe` 内にフック関数（`beforeEach`, `afterEach`, `beforeAll`, `afterAll`）が存在し、スコープ制限の目的がある場合
- 単一の `describe` 内にテストケースが存在しない場合

### ❌ Incorrect

```typescript
// 冗長な単一の describe
describe("正常系", () => {
  it("正しい引数のとき正常に終了すること", () => {
    // ...
  });
});
```

```typescript
// 修飾子が付いていても単一コンテキストであれば報告される
describe.skip("テスト対象", () => {
  it("テストケース", () => {
    // ...
  });
});
```

### ✅ Correct

```typescript
// 単一コンテキストの場合はフラットに記述
it("正しい引数のとき正常に終了すること", () => {
  // ...
});
```

```typescript
// 複数のコンテキストがある場合は describe によるグループ化を許可
describe("正常系", () => {
  it("正しい引数のとき正常に終了すること", () => {
    // ...
  });
});

describe("異常系", () => {
  it("不正な引数のときエラーを返すこと", () => {
    // ...
  });
});
```

```typescript
// フック関数によってスコープが限定されている場合は許可
describe("初期化が必要なテスト", () => {
  beforeEach(() => {
    setup();
  });

  it("正しく初期化されること", () => {
    // ...
  });
});
```

## Options

このルールにオプションはありません。
