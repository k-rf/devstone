## 2. 各サービスの運用指針

### Notion

プロジェクトの要件、仕様、およびタスクの管理場所として扱います。

- **アイデア**:
  - 将来的な構想や検討中の機能案を記録・管理します。
- **PRD**:
  - 機能開発の詳細な仕様や背景、要求事項を定義します。
- **開発タスク**:
  - 開発タスクの内容、受入基準、進捗ステータスは Notion のタスクデータベースで管理します。
  - Git ブランチや PR タイトルに付与する課題キーは、このチケットと 1:1 で対応します。

### GitHub

実装コードのバージョン管理および変更の検証・統合基盤として扱います。

- **ソースコード**: リポジトリ本体でコードを管理します。
- **Pull Request**: レビューおよび CI による品質検証（静的解析・テスト）を行います。
